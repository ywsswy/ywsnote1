战术有几种类型，
1）某个球员传球才触发跑位的，不传球大家就傻站着，这种适合作为单Q指定初始站位；
2）就算不传球就能触发跑位的（也必须满足两个条件：球必须在某手里&大家位置必须到位）：所以也可以通过故意不让某拿球，实现让大家傻站着不动的效果，也能作为初始站位使用；

站位允许左右镜像，具体是左镜像还是右镜像取决于整体球员跑动距离最小的一边

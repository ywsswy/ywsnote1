## 角色
- 管理人：基金公司（例如华夏、景顺长城），负责基金的投资运作，包括选股调仓；
- 托管人：银行，负责保管基金资产，监督管理人的操作；
- 场内普通投资者；
- 资金量达门槛的投资者（容易套利者）：在一级市场申购/赎回；在溢价的时候申购然后在二级市场高价卖出就可以套利；在折价的时候赎回也可以套利；（这个机制也就导致交易价最终会趋近于实际净值）

# 风险
- 股票最糟糕的情况：公司倒闭破产清算，可能损失全部本金；
- ETF最糟糕的情况：基金清盘（当规模过小、流通性过低时，运营成本过高，基金公司可能决定清盘），但基金公司会将基金资产变现并返还给投资者。投资者的损失取决于清盘时基金资产的市场价值；

## ETF分类：
（方式1）跟踪谁
股票型ETF：跟踪股票市场指数，如沪深300ETF、标普500ETF。
债券型ETF：投资于债券指数，如国债ETF。
跨境ETF：投资于海外市场的资产，如纳斯达克100ETF。
（方式2）目标
被动型ETF：明确说明其目标是跟踪某个指数，力求复制指数的表现；
主动型ETF：会提到基金经理通过主动管理，试图超越市场基准或获取超额收益。

## 基金分类：
（方式1）份额是否固定
- 开放式基金：份额不固定，因为可以通过灵活的申购赎回变更总份额；
- 封闭式基金：基金成立后，规模固定，有固定的存期，投资者不能随时申购或赎回，投资者只能在交易所买卖已有的份额，总份额固定；
（方式2）场内外
- 场内基金：在证券交易所（场指的就是这个）内挂牌上市的基金，操作依托于交易所的股票/证券/券商账户。可能存在折价或溢价（市价=场内实时成交价，净值=场外申赎价=实际价值，市价相比净值低或高），例如市价可能受到跟风情绪影响。所以高溢价很危险。包括ETF、LOF。
- 场外基金：不在证券交易所挂牌，只能通过基金公司官网、银行代销、第三方销售平台支付宝微信理财通等场外渠道进行申赎的，没有溢折率只算净值。常由基金经理主动运作，申购赎回需要时间，可能受额度限制（缺点，例如每天最多申购100元），存在风险：如果基金经理的投资决策失误，可能导致基金亏损；包括ETF联结基金（大部分是场外，属于买ETF的基金，所以不等于ETF本身）。
（方式3）场内还分
 ETF：“交易型开放式指数基金”，是一种在交易所上市交易的开放式证券投资基金产品（属于场内基金），可以像股票一样在场内二级市场交易，也可以通过交易所认可的代理券商在一级市场申赎（非常特殊通道，所以通常不叫做场外申赎，只叫场内申赎）；里面包含多支股票（投资标的是投资于一篮子资产，通常跟踪某一指数），所以能一定程度避免单一持股风险；
- LOF：“上市型开放式基金”，可以场内交易，可以场内申赎，还可以场外申赎，ETF的申赎门槛高（例如需要投资者一次性买齐一篮子股票，详见PCF清单，可能一篮子最低要求对应几十万个ETF份额，动辄上百万的资金）套利快（申赎T+0）跟踪指数更准（毕竟不需要现金中转），而LOF的申赎门槛低（投资者只需要用现金操作，基金公司可以灵活地管理现金流，例如等积攒够的时候再去买投资标的，而不需要每次申购都实时立即买入投资标的，毕竟可能投资者投入的现金连买一手都不够）申赎时间慢（T+1），所以对普通投资者而言选择LOF的申赎更像是众筹的感觉；
（方式4）场外还分
-- （场外）公募基金：资产由独立的托管机构（通常是银行）托管，基金公司无法直接接触资金。必须定期披露基金净值（每日）、投资组合（季度）、运作情况等信息，投资者可以随时查询。
-- （场外）私募基金：私募基金的监管相对宽松，信息披露较少，风险最不确定；


# 其他
- 一级市场（净值市场）：跟基金公司交易（申赎）的地方，影响基金总份额。
- 二级市场：基金公司不参与交易的地方，通常就是指场内的买卖交易（换手），不影响基金总份额。

- 跨系统转托管：通常指LOF的场内和场外互转（都是按照份额净值来算，不管你场内溢折率）。（1）场内转场外：例如场内要退市，或者想长期定投不喜欢受场内溢折率波动。（2）场外转场内：场内有高溢价，那转到场内卖出就可以获利。
高溢价非常危险，一旦外汇额度放开申购放开，溢价会瞬间抹平。所以如果场内有一支高溢价的LOF，并且是看好的觉得长期是有赚的话，策略应该是：
如果场外可申购：场内高价时卖出，低价时持有，持续进行场外申购。
如果场外不可申购：那就继续持有，而不是跨系统转托管，毕竟转托管立刻就没有了溢价的利润，不转托管万一还有可能一直保持高溢价不会被抹平。

- HNSW（Hierarchical Navigable Small World）是一种高效的ANN搜索算法，基于分层的图结构设计；相关参数（M：每个节点在检索构图中可以连接多少个邻居节点；construction：写入数据时寻找邻居遍历的范围；ef：检索数据时动态候选元素集合的大小，并不是返回数量的limit参数）


原理
初始化时指定默认ef_参数（探索factor）
内部build部分是图结构，可以拿到一个节点的“邻居”？
请求时可以指定k（topk）和ef参数，内部是取max(k\ef\ef_)来作为大根堆的size；
然后从入口点开始，维护一个大根堆（最后返回的），再维护一个小根堆（边界处有联系的）；
每一轮探索，先判断是否“探索结束”，没结束就先把邻居放到小根堆，然后从小根堆找最近的一个 放进大根堆（放的过程中要保证大根堆的size）；
“探索结束”的条件是：小根堆里全都不比大根堆更相似，并且大根堆size够数了，就可以退出，没必要继续探索了；


参数
m：每个节点在图中（除最底层外）的最大邻居数；
层数：是初始化时通过m参数反推出来的，论文推荐=ln(n) / ln(m)


- Vamana(diskann的内存版)
跟hnsw的区别：
hnsw是多层的结构，越上层跳跃的越大，上层先粗略/快速逼近，然后最后一层详细算邻居；但是vamana是单层的，只不过在建图时会给节点保留一些超远邻居边；
hnsw维护的是两个堆，但是vamana维护的只是一个l_search数组；每次simd算到更近的邻居后就更新进l_search里；最后从l_search里截断topk；

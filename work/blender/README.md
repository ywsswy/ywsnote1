可3d建模软件

## 快捷键
- shift+C，游标回到全局坐标系原点
- 按住中键，变视角
- 按住shift+中键，平移视角
- 滚轮，缩放视角
- 移动：G
- 挤出：E，然后可以切换基础的形式：G（平移挤出）X/Y/Z（特定方向上挤出）S（缩放挤出）
- （物体模式）可以移动缩放旋转一个完整的物体（缩放特殊点：缩放完需要物体->应用缩放，让物体的属性都变成1倍，不然后续操作都是有缩放影响）
- （编辑模式）可以操作一个物体中具体的 点线面，左侧选择功能可以长按，变成款选、刷选、套索选；
- （编辑模式下）上面1/2/3键可以切换点线面模式
- （编辑模式下）可以多选：选下一个的时候按住shift
- （编辑模式下）循环选择一圈点/线：先选择一个，然后按住alt，再点击下一个
- （编辑模式下）调整一串点的曲线弧度：选中一个点，勾选上方的衰减模式，然后按G，然后移动鼠标就可以调整这一串点，滚轮可以选择更多的区域点联动
- （编辑模式下）把一条曲线旋转成一个环：是另一个旋转按钮（有两个按钮，一个是自身旋转，还有一个是挤出旋转）
- （编辑模式下）把一圈线封口成一个面（请确保首尾相接不要有突出来的线头）：选中后按F
- （编辑模式下）透视看：alt+Z
- （编辑模式下）复制一条边：网格->复制，或者快捷键shift+D；
- （编辑模式下）复制一条边（更推荐的【*】，前者是没有连接的，这个在立体里是能跟其他联动的）：选中边，环切并滑移，然后先点击一下边进入模式，然后再单击选x/y/z一条滑轨……很难描述，但是很牛

- 小键盘1：正视图
- 小键盘3：右视图
- 小键盘7，或者右上角点击z：俯视图
- 小键盘9：刚才的视图的反转视图

## 修改器（外挂/高效脚本）
- 好处你可以在不会破坏原点线面的情况下，“预览”某种修改的效果，确定满意后再点击“应用”才会真正的帮你修改点线面；
- 【*】应用之后这次的修改器就不见了，因为已经被采纳了，就无法继续调整修改器的参数了
- 【*】编辑模式是无法点击应用的，必须要切换到物品模式点击应用
- 具体修改器种类：
- 实体化：给一个面加厚度
- 焊接：靠近的点会合二为一
- 表面细分：常用于让球平滑；（而基础功能里的平滑仅用于欺骗眼睛看起来平滑，并没有起到修改作用）

## 功能
- 桥接循环边：例如杯子把手，上面画一圈线，下面画一圈线，就可以通过桥接循环边连成一个把手

## 常见问题
- 快捷键没反应，可能当前是中文输入法
- 如果有重叠的两条线，只能选中一条（应该是偏短的那条），所以设计上尽量不要搞重叠
- 问题定位很多时候是因为重叠、面的朝向等没搞对导致的，所以可以在右上角开启叠加（面朝向、统计信息）来辅助debug；
- 两条看似相交的边，怎么在相交处创建交点：每条边细分出一个点，然后对细分的点进行G（移动），移动前勾选上上方的吸附（边+移动），两个点应该就重合了；合并两个点的方法：
- （方法1）透视模式选中2个点，选择网格->合并；
- （方法2）把其中一个点拉出来，这样肉眼看就不会重叠，然后选中两个，合并到其中一个；
- （方法3）a全选所有点，按距离delta合并（0.001），肯定能把这俩合并掉；
- 翻转一个面：网格->法线->翻转
- 使用工具：编辑->偏好里勾选启用工具（有个looptool可以用来把一圈点调整成圆），然后在右上角有个箭头可以拉出来使用
- 查看一个点的坐标：点击一个点，然后按N看条目信息
- 面的细分，必须要长方形？必须每天边上没有多余的点
- 对多条边封成一个面，必须选中每一条边，不能仅选中对向的两条
- 沿着某条线的方向移动点，而不是沿着x/y/z轴：
- （方法1）按两次G（但是这种是按照系数单位来，看不到绝对距离）
- （方法2）选中一条边，然后页面顶部找到坐标系下拉框，点击+号，创建一个自定义的edge；然后此时移动就是以这条边作为坐标系啦；
- 把一张2D图片生成平面点线：先导入参考图片，然后右键转换成蜡笔，然后最后转换成“网格”

* 为什么使用共享会话密钥（对称密钥），因为这个加密解密速度快



物理上有三个位置：
客户端 中间网络设备 服务端
https解决的是“让 中间网络设备 无法解密（读） 无法篡改（写）两端传输的数据”

思路是，双方先明确使用一个密钥（对称的），然后后续传输原始数据时都用这个密钥来加密




https为什么安全：

server端会返回 服务器的CA证书；
客户端可以通过判断是否信任CA，已经使用该CA的公钥验证证书的签名是否正确；

客户端与服务端之间的传输内容的是经过加密了的，中间人拿到也无法解密；



CA证书包含两部分：
- 主体内容：域名、公钥（服务器的）、有效期、颁发者
- CA 的数字签名：对上面主体的签名；

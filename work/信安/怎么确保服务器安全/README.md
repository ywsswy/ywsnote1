- VNC登录(Virtual Network Computing)，算远程桌面技术，不走ssh的链路，所以ssh密钥丢了可以用VNC登录
- MFA = Multi-Factor Authentication，多因子认证，登录时要求提供两个或以上不同类型的"凭证"才能通过（两个就叫2FA），常见密码+OTP；
- OTP：One-Time Password，TOTP就是基于时间的OTP，手机计算OTP的客户端可以用google authenticator
- PAM：可插拔认证模块，可以在ssh里配置
- 对称密码：分组密码(DES,IDEA,AES)和流密码(RC4)；缺点秘钥管理困难
- 非对称密码：RSA、ELGamal、椭圆曲线ECC；缺点加解密效率低；
（1）先用私钥加密（发送方进行数字签名），再用公钥解密（接收方进行验证签名）；
（2）先用公钥加密（现实生活中有点像信箱的例子），再用私钥解密：防偷看；
- 计算机可以在多项式时间复杂度内解决的问题：P类问题（Polynomial），不可解决则是NP
- Hash函数：只有加密，没有解密：（MD5、SHA）
